# Freeze IOS-C0-v1 declarations and unavailable iOS 26 scaffold with exclusive manifest transfer

C0 uses Swift 5.10/strict concurrency without dependency upgrades, opaque document/root identity plus revision, binding UUID and selection/access generations, a synchronous MainActor native writer, immutable observers with subscriber-owned cancellation, UIDocument-only serialized document persistence with baseline-only acknowledgement, leased/coordinated I/O, and operation-owned persisted image assets before source insertion. Source+preview, Files/iCloud, iPhone/iPad single scene and the deferred feature boundaries follow the approved handoff packet. Move only the immutable syntax token declaration and keep a Mac typealias; parser/fold/grammar extraction stays with 02, portable tree/physical sidecars with 03. PreviewKitContracts is a separate pure product so C0 and 06 can import the frozen seams without linking AppKit or creating a WorkspaceKitIOS/PreviewKit cycle; full PreviewKit port remains 07. Contracts/composition stay with 13; package and global manifest handoff is recorded in the integration ledger, with global files exclusively 12 after transfer. 13 also updates the existing EditorReplaceLayeringTests exact architecture inventory for these approved manifests/targets, extends it to all eight packages and both app source trees, and adds pure/UI isolation checks while retaining mutation bans and third-party/npm pins. The bootstrap app contains no provider or document and cannot enable production composition before M0 actual IME/Undo, Files/iCloud, background persistence and owner re-sign/install plus real providers. Local compilation, runtime execution, exact-head CI and device/IPA/performance evidence remain separate. Alternatives: duplicate token enums, implicit parent grants, stale markSaved/live-source resets, successful fallback providers and competing shared-manifest authors were rejected.
