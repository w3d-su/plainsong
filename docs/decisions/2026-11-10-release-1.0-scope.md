# Release 1.0 scope: V1, V2, V5 and V6

Date: 2026-11-10. Owner decisions on `docs/release-1.0-scope.md` §1.

## Decision

- **V1.** macOS and iOS do not ship 1.0 together. macOS 1.0 comes first; iOS follows as
  its own 1.0.
- **V2.** Independent windows are in macOS 1.0 through Windows PR D2. Native tabs (F),
  restoration (E) and residency (G) are Should.
- **V5.** In-app updates are Must for macOS 1.0, not Should.
- **V6.** The release is `1.0.0`, with `0.9.x` betas before it.

V3 (WYSIWYG status) waits for the owner's Zhuyin/Pinyin dogfood. V4 (distribution
channel) is open: the owner said the same day that the Apple Developer Program
membership will not be bought in the short term, so the scope document assumes an
unsigned direct DMG until the owner confirms that or changes it.

## Why

- V1: every iOS device gate is open and needs hardware and a signing identity. Tying the
  platforms would block macOS on evidence nobody can produce yet.
- V2: without D2 a user cannot work in a second window, so 1.0 would be single-window
  with the window work half shipped.
- V5: a user who installs an unsigned build by hand has no way to learn about the next
  one. The reason to wait for Developer ID signing was the risk that Gatekeeper would
  block an unsigned app again after each update. An owner-run probe on 2026-11-10 updated
  an unsigned build through Sparkle with no second prompt
  (`docs/auto-update-plan.md` §5).
- V6: the draft's naming, kept. Whether the builds are signed is V4's question, not the
  version number's.

## Alternatives considered

- Keeping updates as Should with a documented manual path: rejected by the owner.
- Reserving `1.0.0` for the first Developer ID-signed build and staying on `0.x` until
  then: not chosen. It would leave 1.0 without a date while the membership is not planned.

## Consequences

- With V4's unsigned assumption, U-D2 in `docs/auto-update-plan.md` becomes "before
  signing". U-D4, U-D6 and U-D7 still need the owner, and U-D6 reverses the 2026-07-02
  no-secrets rule with its own entry.
- The probe was one update on one Mac. U3 repeats it on the real feed before the README
  drops "no auto-update".
