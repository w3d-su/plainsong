All four findings in pending review `5649020476` apply to the historical
`fdd2a071c04f61f5259d31cf17699534d77fce9e` source and to the corresponding code on main.

- Stale bookmark restore now mints the replacement inside `adopt`, after scope
  admission and metadata validation. A failed admission or mint keeps the old bytes,
  marks them for reselection, and balances only a newly started scope.
- A clean, unfenced document can close with an uninstalled or deferred reload proposal.
  Issued reads drain before provider close and lease release. Close installs no external
  text and writes no provider bytes. Dirty source and unavailable/conflict fences still retain.
- Replacement retirement returns its latest new recovery receipt to a concurrent close
  and publishes durable recovery events. A receipt from a draft saved before retirement
  does not turn a currently clean close into a retained draft.
- Root presenters stay registered after eviction. Root change refreshes a directory or
  reports the granted single file. Root deletion revokes the grant. An unproved root
  move revokes admission and marks the recent bookmark for reselection; it never guesses
  a destination or reports the root name as a child path. Existing leases drain normally.
